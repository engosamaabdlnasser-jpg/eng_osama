# ENG OSAMA V12.1 — Language + AI Assistant

## 1) Bilingual system
- Arabic/English switcher in the header.
- Locale is stored in localStorage under `eng-osama-locale`.
- `document.lang` and `document.dir` update without reload.
- Translation keys live in `src/i18n.tsx`.
- Dynamic course/lesson/category fields support AR/EN.

Run once in Supabase:
- `supabase/V12-BILINGUAL-CONTENT.sql`

Then fill English content from Admin Course editor where needed.

## 2) AI assistant
The assistant has a provider-neutral UI and a Supabase Edge Function:
- `supabase/functions/assistant-chat/index.ts`
- model: Gemini 2.5 Flash-Lite free tier
- the API key is kept server-side in Supabase secrets; never put it in Vite/frontend env.

Set the secret in Supabase:
`GEMINI_API_KEY=...`

Deploy the function with the Supabase CLI or your normal Supabase deployment workflow.

If the AI function is unavailable, the UI falls back to the built-in safe assistant replies.

## 3) Assistant Inbox
Run once:
- `supabase/V12-ASSISTANT-SUPPORT.sql`

This creates support requests plus:
- `assistant_conversations`
- `assistant_messages`

The Admin panel gets a **رسائل المساعد / Assistant messages** tab.

## 4) Important security rule
Do not put `GEMINI_API_KEY` in `.env` with `VITE_` prefix. It must stay in Supabase Edge Function secrets.
